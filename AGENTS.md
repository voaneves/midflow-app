# AGENTS.md — Project Specifications & Operational Rules

## 1. Critical Workflow & Git Rules (Mandatory)

1. **Never Commit or Push Automatically**
   - Do **not** run `git commit`, `git push`, `git reset`, or any command that creates commits or mutates remote state.
   - Leave all staging, committing, and pushing to the user.

2. **Always Provide a PowerShell One-Liner at the End**
   - Whenever code, configuration, or documentation is created or modified, conclude your response with a single ready-to-run **PowerShell one-liner** (`;`-separated) so the user can stage, commit, and push in one step.
   - Example format:
     ```powershell
     git add -A; git commit -m "feat: concise human commit message"; git push -u origin main
     ```

3. **Zero Mention of AI Generation**
   - Never reference AI generation, LLMs, coding assistants, or automated authoring in commit messages, code comments, documentation, PR descriptions, or UI copy.
   - Never add `Co-Authored-By:` trailers or "Generated by..." attribution anywhere.
   - Use clean, standard Conventional Commits (`feat:`, `fix:`, `refactor:`, `chore:`, `docs:`, `test:`) written from a human developer perspective.

## 2. Security & Data Protection Rules

1. **Server-Side Secrets Only**
   - API keys and tokens (`GEMINI_API_KEY`, `OPENAI_API_KEY`, `CF_ACCOUNT_ID`, `CF_API_TOKEN`, `ADMIN_TOKEN`) must remain exclusively in server environment variables (`.env`).
   - **Never** prefix any secret or credential with `VITE_` (Vite bundles `VITE_*` variables into client-side JavaScript).
   - Never hardcode credentials, tokens, or private endpoints in source files or tests.

2. **Never Commit Sensitive or Runtime Files**
   - Keep `.env`, `.env.*` (except `.env.example`), and `server/data/` (which stores client briefings, evaluation logs, and `events.jsonl`) out of version control.

3. **Input Validation & Sanitization**
   - Validate all incoming payloads in `server/routes.ts`.
   - Sanitize HEX color values, photo identifiers, and user strings before injecting into SVG, canvas templates, or HTML responses.
   - Preserve per-IP rate limiting and HTTP security headers (`Content-Security-Policy`, `X-Frame-Options`, `X-Content-Type-Options`, `Strict-Transport-Security`).

## 3. Product Specifications (MIDFLOW)

- **Domain & Purpose**: **MIDFLOW** (`Midflow.com.br`) is a content studio for Brazilian small and medium businesses. A short guided briefing generates ready-to-publish Instagram Feed posts, 4-screen narrative Stories sequences, captions, and hashtags.
- **Language Conventions**:
  - **User-Facing UI & Copy**: **Brazilian Portuguese (`pt-BR`)** — all screens, buttons, validation messages, generated social copy, and operational guides ([PRODUCAO.md](PRODUCAO.md)).
  - **Codebase & Technical Specs**: **English** — TypeScript identifiers, types, comments, [README.md](README.md), and [plan.md](plan.md).
- **Core Product Flow**:
  1. **Landing & Onboarding** ([`Landing.tsx`](src/pages/Landing.tsx), [`Auth.tsx`](src/pages/Auth.tsx)) — includes one-click demo mode (*"Ver demonstração"* / Studio Aurora).
  2. **Step 1 — Briefing** ([`Step1Briefing.tsx`](src/pages/app/create/Step1Briefing.tsx)) — business profile, segment, city/location, objectives, target audience, tone of voice, visual style, up to 5 HEX brand colors, and output formats.
  3. **Step 2 — Conteúdo** ([`Step2Content.tsx`](src/pages/app/create/Step2Content.tsx)) — format selection, segment-tailored theme suggestions across categories, and post objective.
  4. **Step 3 — Estilo** ([`Step3Style.tsx`](src/pages/app/create/Step3Style.tsx)) — brand identity vs. suggested palette, logo upload, 6 visual styles (`Moderno`, `Minimalista`, `Elegante`, `Colorido`, `Natural`, `Premium`), image mode, tone chips, and aspect ratio (`1:1` or `4:5`), with real-time preview.
  5. **Step 4 — Gerar Criativos** ([`Step4Generate.tsx`](src/pages/app/create/Step4Generate.tsx)) — generates 4 Feed posts + 4 narrative Stories (`Hook → Problem/Need → Solution/Benefit → CTA`), quality score badge, interactive Instagram phone mockup, modal editor ([`Editor.tsx`](src/components/creative/Editor.tsx)), single PNG export, batch ZIP download, and library persistence.
- **Plans**:
  - `Start` (R$ 47) · `Pro` (R$ 77) · `Business` (R$ 127).

## 4. Architecture & Technical Specifications

### Tech Stack
- **Runtime**: Node.js `>=22.18` (runs server TypeScript directly via `node --env-file-if-exists=.env server/server.ts`).
- **Frontend**: React 19, TypeScript ~6.0, Vite 8, Tailwind CSS v4 (`@theme` tokens in [`src/index.css`](src/index.css)), React Router 7 (`HashRouter`), Zustand 5 (`localStorage` persistence in [`src/lib/store.ts`](src/lib/store.ts)).
- **Typography & Assets**: Self-hosted Fontsource fonts (`Plus Jakarta Sans`, `Playfair Display`, `DM Serif Display`, `Montserrat`, `DM Sans`) and `lucide-react` icons so client-side PNG/ZIP exports (`html-to-image` + `jszip`) work offline without CORS tainting.

### Key Modules
| Path | Responsibility |
|---|---|
| [`src/components/creative/Creative.tsx`](src/components/creative/Creative.tsx) | Single WYSIWYG canvas renderer (`1080×1080`, `1080×1350`, `1080×1920`) scaled via CSS across thumbnails, phone mockup, editor, and PNG export |
| [`src/components/creative/Editor.tsx`](src/components/creative/Editor.tsx) | Creative editor modal (copy fields, text rewrite, custom image generation, layout/palette/photo swap) |
| [`src/lib/store.ts`](src/lib/store.ts) | Persisted Zustand state (brand profile, 3-step draft, generation versions, saved library, plan usage) |
| [`src/lib/data.ts`](src/lib/data.ts) | Segments, theme catalogs, copy banks, visual styles, tones, objectives, and plan definitions |
| [`src/lib/generator.ts`](src/lib/generator.ts) | Deterministic template generator used as an offline/fallback engine |
| [`server/server.ts`](server/server.ts) & [`server/routes.ts`](server/routes.ts) | Production HTTP server, REST API (`/api/generate`, `/api/rewrite`, `/api/image`, `/api/feedback`, `/api/health`, `/api/admin/metrics`), rate limiting, and security headers |
| [`server/ai/quality.ts`](server/ai/quality.ts) | Automated quality gate (0–100 score): enforces character limits, highlight substring match, brand mention, 5–12 unique hashtags, non-placeholder copy, 4 posts + 4 stories completeness, and strips hallucinated prices not present in the briefing |

### Design & Engineering Invariants
- **WYSIWYG Rendering**: Any visual change to a creative style must be made inside [`Creative.tsx`](src/components/creative/Creative.tsx) at the 1080-px coordinate space so thumbnails, previews, and exported PNGs stay identical.
- **Quality Gate Compliance**: Any change to prompts (`server/ai/prompt.ts`) or generation schemas must pass `npm test` and maintain a quality score `>= 85` in `npm run eval`.
- **Honest Fallback**: Never disguise template fallback output as live model output; preserve engine status reporting (`ai` vs. `fallback`).
- **Accessibility & Motion**: Respect `prefers-reduced-motion` across all CSS and component animations ([`src/index.css`](src/index.css), [`src/components/motion.tsx`](src/components/motion.tsx)).
